# 实验三 · 极简待办网站「小待办」项目说明文档

> 课程作业：使用 Vue 实现一个纯前端网站。
> 公网地址：<https://mjh134.github.io/treasure-game/blog/>
> 同一个仓库里的寻宝游戏（实验一/二）仍在根地址 <https://mjh134.github.io/treasure-game/>，两者互不影响。

---

## 一、这是个什么网站（一句话）

一个用 **Vue 3 + Vite + Vue Router** 做的**极简待办清单网站**，纯前端、无后端，共 **3 个页面、16 个单文件组件**，覆盖 [Vue 官方教程](https://cn.vuejs.org/tutorial/) 的主要知识点。刻意做得很小、每个组件只干一件事，方便理解和上台讲解。

### 三个页面
| 地址（hash 路由） | 页面文件 | 作用 |
|---|---|---|
| `#/` | `views/HomeView.vue` | 首页：打招呼 + 计数器 |
| `#/todo` | `views/TodoView.vue` | 待办：增 / 删 / 勾选完成 |
| `#/about` | `views/AboutView.vue` | 关于：站点简介 + 留言表单 |

> 用「哈希路由」是为了部署到 GitHub Pages 这种纯静态托管时，刷新子页面也不会 404。

## 四、整站怎么跑起来的（讲这条主线就够）

1. 浏览器加载 `index.html` → 执行 `src/main.js` → 创建 Vue 应用、注册路由、挂载到 `#app`。
2. `App.vue` 渲染固定页头/页脚，中间用 `<RouterView>` 显示「当前路由对应的页面」。
3. `App.vue` 用 `provide` 把「主题」提供给任意深度的子组件（`ThemeToggle` 用 `inject` 拿到并切换）。
4. 页面里用到的功能都拆成小组件，通过 **props 传数据 / emit 传事件** 组合起来。
5. 因为数据都是响应式的（`ref` / `reactive` / `computed`），改数据后界面自动更新，不用手动操作 DOM。

## 五、16 个单文件组件逐个说明

每个 `.vue` 文件顶部都有一行 `// 演示知识点：…`，讲解时直接对着念即可。

**框架 / 布局（6）**
- `App.vue`：根组件；`provide/inject`、`watchEffect`、`<RouterView>`。
- `AppHeader.vue`：页头，组合 `NavBar` + `ThemeToggle`（组件嵌套）。
- `AppFooter.vue`：页脚；插值 + `computed` 年份。
- `NavBar.vue`：三个 `<RouterLink>` + 激活样式。
- `ThemeToggle.vue`：`inject` 主题并切换明/暗。
- `BaseCard.vue`：通用卡片外壳，只用一个**默认插槽**装内容。

**可复用小零件（2）**
- `BaseButton.vue`：按钮；**默认插槽**装文字，`emit` 一个 `click`。
- `Badge.vue`：数字小圆标；`props` + 动态 `class`。

**首页用（2）**
- `Greeting.vue`：`props` 名字 + `v-if/v-else` 显示不同问候。
- `Counter.vue`：`ref` 计数 + `computed` 双倍值，复用 `BaseButton`/`Badge`。

**待办页用（2）**
- `TodoInput.vue`：`defineModel`（自定义组件的 `v-model`）+ 回车事件 + `emit('add')`。
- `TodoItem.vue`：`props` 一条待办 + `emit('toggle' / 'remove')` + 动态 class。

**关于页用（1）**
- `AboutForm.vue`：`reactive` 表单 + `v-model` + `computed` 校验 + `watch` + `emit('submit')`。

**页面视图（3）**
- `HomeView.vue`：打招呼 + 计数器，含 `onMounted`。
- `TodoView.vue`：待办核心，管理一个 `ref` 数组，`v-for` 渲染、`computed` 统计、响应子组件事件完成增删改。
- `AboutView.vue`：简介 + 接收 `AboutForm` 提交的留言。

## 六、教程知识点 → 在哪个文件

| 知识点 | 位置 |
|---|---|
| 插值 `{{ }}` | 几乎所有组件，如 `AppFooter.vue` |
| `v-bind`（`:属性`/动态 class） | `Badge.vue`、`TodoItem.vue`、`Counter.vue` |
| `v-on`（`@事件`） | `ThemeToggle.vue`、`TodoInput.vue`（`@keyup.enter`） |
| `v-model`（表单双向绑定） | `AboutForm.vue`、`TodoInput.vue` |
| 自定义组件 `v-model`（`defineModel`） | `TodoInput.vue` |
| `v-for` 列表 + `:key` | `TodoView.vue`、`AboutView.vue` |
| `v-if / v-else` | `Greeting.vue`、`TodoView.vue`、`AboutView.vue` |
| `computed` 计算属性 | `Counter.vue`、`TodoView.vue`、`AboutForm.vue` |
| `watch` 侦听器 | `AboutForm.vue` |
| `watchEffect` | `App.vue`（同步主题到 `data-theme`） |
| `ref` / `reactive` | `Counter.vue`、`AboutForm.vue` 等 |
| `props` | `Greeting.vue`、`Badge.vue`、`TodoItem.vue` |
| `emit` | `BaseButton.vue`、`TodoInput.vue`、`TodoItem.vue`、`AboutForm.vue` |
| 插槽 `slot` | `BaseCard.vue`、`BaseButton.vue` |
| `provide / inject` | `App.vue` 提供主题，`ThemeToggle.vue` 注入 |
| 生命周期 `onMounted` | `HomeView.vue` |
| Vue Router（路由 / 懒加载 / `RouterLink`） | `router/index.js`、`NavBar.vue`、`App.vue` |

## 七、部署说明（GitHub Pages）

站点挂在已有的 `treasure-game` 仓库上，和寻宝游戏共存：

- 寻宝游戏：`main` 分支根目录 → <https://mjh134.github.io/treasure-game/>
- Vue 待办站：`main` 分支下的 `blog/` 目录（Vite 打包产物）→ <https://mjh134.github.io/treasure-game/blog/>

要点：
1. `vite.config.js` 里 `base: '/treasure-game/blog/'`，保证资源路径正确。
2. GitHub Pages 的发布源是 **`main` 分支 / 根目录**（所以游戏在 `/`，网站在 `/blog/`）。
3. 目录名沿用 `blog` 只是一个路径名，没有别的意思。

### 以后更新这个站的做法
```bash
# 1) 改代码后重新构建
cd 实验三
npm run build

# 2) 用 dist 覆盖仓库根目录的 blog/（PowerShell 示例）
cd ..
Remove-Item -Recurse -Force blog
New-Item -ItemType Directory blog
Copy-Item -Recurse -Force 实验三\dist\* blog\

# 3) 只提交 blog/ 和源码目录，绝不带上游戏文件的删除
git add -A -- blog 实验三
git commit -m "更新待办站"
git push github main
```
> ⚠️ 一定用 `git add -A -- blog 实验三` 指定路径，**不要** `git add -A .`。
> 因为寻宝游戏的 `index.html` 等文件在本机工作区是被删除状态（只在 git 历史里），
> 全量 add 会把这些删除一起提交，从而**弄坏寻宝游戏**。

## 八、上台讲解小抄

1. **先说是什么**：「Vue3 + Vite + Vue Router 做的极简三页待办网站，纯前端，16 个组件，覆盖教程知识点。」
2. **走一条数据流**：`main.js` 挂载 → `App.vue` 的 `<RouterView>` 出页面 → 主题用 `provide/inject` 切换 → 待办页 `TodoView` 用一个 `ref` 数组，子组件 `TodoInput/TodoItem` 用 `emit` 通知它增删改 → `computed` 实时统计未完成数。
3. **被问到某知识点**：翻对应文件第一行注释，或对照第六节表格。
4. **现场演示**：打个招呼(props)、点计数器(computed)、加/勾/删待办(v-for+emit)、切主题(provide/inject)、发留言(v-model+watch+emit)。

## 九、注意事项

- 封面/图标无外链依赖，图片相关的问题没有了。
- 主题不做持久化，刷新后回到亮色（如需可用 `localStorage`，属于加分项）。
- 寻宝游戏和本应用分别占 `/` 与 `/blog/`，改这个站不会影响那个游戏，反之亦然。
