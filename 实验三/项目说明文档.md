## 一、项目简介

「拾光博客」是一个 **纯前端**（无后端）的个人博客站点，数据用本地数组模拟，主要用来完整覆盖
[Vue 官方交互式教程](https://cn.vuejs.org/tutorial/) 中的核心知识点。

- **技术栈**：Vue 3（组合式 API `<script setup>`）+ Vite 构建 + Vue Router 4（页面路由）。
- **页面数**：4 个（首页 / 文章详情 / 写博文 / 关于），满足「至少 3 个页面」。
- **单文件组件数**：27 个 `.vue`（22 个子组件 + `App.vue` + 4 个页面视图），满足「至少 15 个组件」。
- **交互功能**：搜索、分类筛选、点赞、发表评论、发布新文章、删除文章、明暗主题切换、页面切换动画、全局轻提示。

### 它长什么样（4 个页面）
| 路由（hash） | 页面文件 | 作用 |
|---|---|---|
| `#/` | `views/HomeView.vue` | 首页：统计条 + 搜索框 + 分类筛选 + 文章卡片列表 |
| `#/post/:id` | `views/PostView.vue` | 详情：正文、点赞、评论、作者卡、阅读进度条 |
| `#/write` | `views/NewPostView.vue` | 写博文：表单发布新文章 |
| `#/about` | `views/AboutView.vue` | 关于：个人简介 + 知识点清单 + 链接 |

> 用「哈希路由」(`createWebHashHistory`) 是为了部署到 GitHub Pages 这类纯静态托管时，刷新子页面也不会 404。

## 二、如何本地运行

需要 Node.js（本项目在 v22 下验证）。


## 四、整体运行流程（代码逻辑主线）

把整站想成「一条数据流」：

1. **启动**：浏览器加载 `index.html` → 执行 `src/main.js` → `createApp(App)` 创建应用、注册 `router`、挂载到 `#app`。
2. **框架**：`App.vue` 渲染页头 `AppHeader`、页脚 `AppFooter`，中间是 `<RouterView>`（当前路由对应的页面渲染处），并 `provide` 出主题状态供任意后代 `inject`。
3. **数据**：所有文章/评论/搜索状态集中在 `store/blog.js` 的一个 `reactive` 对象 `blogStore` 里。谁需要谁 `import`，天然跨组件共享（这是全局状态的简化做法，思路同 Pinia）。
4. **页面**：
   - 首页从 `blogStore.filteredPosts`（计算属性）拿过滤后的列表渲染卡片；
   - 点卡片 → 跳到 `#/post/:id` → 详情页用 `route.params.id` 找到对应文章渲染；
   - 写博文页提交 → `addPost()` 写入 store → 跳详情；
   - 详情页发表评论 → `addComment()` 写入 store → 列表与统计自动更新。
5. **响应式**：因为数据都是 `ref/reactive/computed`，任何一处修改后，所有用到它的界面会**自动重新渲染**，无需手动操作 DOM。

## 五、核心数据源讲解：`store/blog.js`

```js
export const blogStore = reactive({
  posts: seedPosts,        // 文章数组
  comments: {},            // { 文章id: [评论...] }
  search: '',              // 搜索关键词
  activeCategory: '全部',  // 当前分类
  filteredPosts: computed(...) // 依 search + activeCategory 计算出的可见列表
  categories: computed(...)    // 从文章里提取出的所有分类
  stats: computed(...)         // 文章/标签/评论数量
})
```

- `filteredPosts` 是**计算属性**：搜索词或分类一变，它自动重算，首页列表随之更新（演示 `computed` + 响应式）。
- 同文件还导出 `findPost / addPost / removePost / addComment / getComments` 五个函数，负责增删改查，页面组件调用它们修改 `blogStore`。

`data/posts.js` 目前只有一条 `test` 文章（作业要求把首页只保留一个 test 文档）。想加回多篇文章，直接往数组里追加对象即可，字段保持和 `test` 一致。

## 六、组件清单（22 个子组件 + App + 4 视图）

每个组件头部都有一行 `// 演示知识点：...` 注释，下面按功能归类：

**布局类**
- `App.vue`：根组件；`<RouterView>`、`provide/inject`、`watchEffect`、`<Transition>`、动态组件 `<component :is>`。
- `AppHeader.vue`：页头，组合 NavBar + ThemeToggle，含**默认插槽** `<slot>`。
- `AppFooter.vue`：页脚，`computed` 显示当前年份。
- `NavBar.vue`：顶部导航，`<RouterLink>` 与激活样式 `.router-link-active`。
- `ThemeToggle.vue`：`inject` 主题并切换按钮。

**首页列表类**
- `SearchBar.vue`：**`defineModel` 实现自定义组件 v-model**，搜索框。
- `CategoryFilter.vue`：`props` 数组 + `defineModel` + `v-for` + 动态 `class`。
- `PostList.vue`：`v-for` 渲染卡片，`v-if/v-else` 切换空状态。
- `PostCard.vue`：`props` 接收整篇、`computed` 格式化日期、`<RouterLink :to="{params}">` 传参。
- `TagBadge.vue`：`props` + `emit('select')`，标签徽章。
- `StatBar.vue`：`props` 数组渲染统计数字。
- `EmptyState.vue`：**具名插槽 + 默认插槽**，空状态占位。

**详情页类**
- `ReadProgress.vue`：`onMounted/onBeforeUnmount` 监听滚动、`:style` 动态进度条。
- `PostContent.vue`：`computed` 把正文按空行切段，`v-for` 渲染 `<p>`。
- `AuthorCard.vue`：`props` 多字段，计算首字母头像。
- `BackButton.vue`：`useRouter().back()` 编程式返回。
- `CommentList.vue`：`props` 数组 + `v-for` + `v-if`。
- `CommentItem.vue`：`props` 单条评论，时间格式化。
- `CommentForm.vue`：`ref` 本地状态 + `v-model` + `emit('submit')` + 校验。

**写作 / 关于类**
- `PostEditor.vue`：`reactive` 表单、`v-model`（input/textarea/select）、`computed` 校验、`watch`、`emit`。
- `ProfileCard.vue`：`props` + 默认插槽 + `v-for` 技能标签。
- `SocialLinks.vue`：`v-for` 渲染外链，动态 `:href`。

**全局提示类**
- `Toast.vue`：`<Teleport to="body">` + `<Transition>`，配合 `composables/useToast.js`。

## 八、部署说明（GitHub Pages）

站点挂在已有的 `treasure-game` 仓库上，**和寻宝游戏共存**：

- 寻宝游戏：`main` 分支根目录（`index.html`）→ <https://mjh134.github.io/treasure-game/>
- Vue 博客：`main` 分支下的 `blog/` 目录（Vite 打包产物）→ <https://mjh134.github.io/treasure-game/blog/>

关键点：
1. `vite.config.js` 里 `base: '/treasure-game/blog/'`，保证打包后的资源路径正确。
2. GitHub Pages 的发布源设为 **`main` 分支 / 根目录**（所以游戏仍在 `/`，博客在 `/blog/`）。
3. 部署方式：本地 `npm run build` 得到 `dist/` → 把 `dist/` 内容复制到仓库根目录的 `blog/` → 提交并 push 到 `main` → Pages 自动重建。

### 更新博客时的完整流程（手动）
```bash
# 1) 改代码后重新构建
cd 实验三
npm run build

# 2) 把 dist 覆盖到仓库根的 blog/（PowerShell 示例）
cd ..
Remove-Item -Recurse -Force blog
New-Item -ItemType Directory blog
Copy-Item -Recurse -Force 实验三\dist\* blog\

# 3) 只提交 blog/ 和源码目录，避免误动游戏文件
git add -A -- blog 实验三
git commit -m "更新博客"
git push github main
```
> ⚠️ 一定用 `git add -A -- blog 实验三` 指定路径，**不要** `git add -A .`，以免把仓库根里被删除的游戏文件（`index.html` 等）一并提交，破坏寻宝游戏。

## 十、已知小问题 / 注意事项

- **封面图依赖外链** `picsum.photos`，网络不好时图片加载慢或超时（不影响功能）。
- **页面切换用了 `<Transition mode="out-in">`**：若浏览器标签处于后台（未聚焦），动画帧被暂停，点击导航可能出现「地址变了但页面暂时没切换」的现象；**在前台正常使用的浏览器里不会发生**。如想去掉该依赖，可把 `App.vue` 里的 `mode="out-in"` 删除或去掉整个 `Transition` 包裹后重新构建部署。
- 首页目前按要求只保留一条 `test` 文章，想恢复多篇直接编辑 `src/data/posts.js` 即可。
